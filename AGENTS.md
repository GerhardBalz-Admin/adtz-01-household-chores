# Agent instructions

This repository is the AI Dev Tools Zoomcamp 2026 Homework 1 Django household-chores exercise. Read `_docs/plan.md` and the existing backlog before changing behavior. Keep changes within the agreed homework scope.

## Environment and commands

Use `uv` for Python dependency management:

- `uv sync` — install locked dependencies.
- `uv add <package-name>` — add a dependency when the task needs one.
- `uv run python manage.py runserver` — run the Django development server.
- `uv run python manage.py test` — run the Django test suite.

## Working practice

Implement one backlog task at a time, run the relevant tests, and commit meaningful changes regularly. Do not claim a task is verified until its tests have run successfully.
